
## Under the hood

This template is generated from the open-source
[E2B Code Interpreter](https://github.com/e2b-dev/code-interpreter) template (Apache-2.0, see
[LICENSE](../LICENSE)) by `scripts/sync_upstream.py` and built with the BoxFab SDK. Everything in
this directory is generated: change the rules in the script, not the files.
[UPSTREAM.md](../UPSTREAM.md) lists every change.
